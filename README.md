# CSM Copilot private marketplace

Current Candidate: **0.2.27-candidate.live.codex.20261027130357**.

This repository contains the exact frozen plugin for controlled Candidate installation and acceptance testing. It is separate from the main CSM Copilot release. Plugin files must not be edited here.

Outreach prepares a separate email for each selected contact. Emails reuse the same account research and current guide, while each keeps its own wording review, approvals and draft status. The first email remains unchanged.

This Candidate also includes the renewal preparation coordinator for the approved brief, authorized charts and the next card-selection action.

Private setup files, credentials, feedback configuration, source evidence and case records remain outside Git. This upload does not claim that the exact Candidate has completed live or clean non-owner acceptance, or approve wider distribution.
