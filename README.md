# CSM Copilot private marketplace

This is a frozen release source, not the development repository. Plugin files must not be edited here. Use a private, company-approved repository and pin the tested release commit.

After installation, run the packaged setup workflow with the separate private setup file. Each user authenticates independently. Installation does not grant data access. The setup file, credentials, feedback configuration and case records must never be committed.

Candidate and invented exports are not approved tester releases. Publishing and installation require separate authorization.
